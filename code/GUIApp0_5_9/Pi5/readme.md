### Raspberry Pi 5 configuration:
 - Raspberry Pi 5 (min 1 GB RAM)
 - Real Time Clock battery (rechargeable)
 - RFID module PN532 V3
 - 5V 3007 Fan PWM Speed Adjustable CPU Cooling fan
 - LED, RGB model WS2812D
 - Cable for camera, MIPI 22-pin to FPC 15-pin (CSI), 8 cm
 - Lithium RTC clock battery, 3 V
 - Pi camera module 1, 2 or 3

### Wiring schematics Raspberry Pi 5
Make sure you use the correct 3D case files as there is versions with and without RGB- LED diod. Use 2 mm screws with the right lenght during assembly.

### Software and operating system
The full image can be burned to a microSD- card with minimum 32 gb storage. Make sure to use a high quality card.
Note, the image is only operational with specified hardware stated above. The RFID module and RGB- LED diod is optional.
The GUIApp.py version 0.5.9 can be installed using GUIApp0_5_9_Pi5.tar.gz. It needs the the full image (operating system) version 0.5.9 or later to be installed first.
