## Code for Raspberry Pi 2 W and Raspberry Pi 5:
### Raspberry Pi Zero 2 W configuration:
 - Raspberry Pi Zero 2W
 - RTC DS1307
 - RC522 RFID module
 - Pi camera module 1, 2 or 3

### Wiring schematics Raspberry Pi Zero 2 W:
Make sure to use the correct Lid as the camera modules differ in height. Use 2 mm screws with the right lenght.

### Raspberry Pi 5 configuration:
 - Raspberry Pi 5 (min 1 GB RAM)
 - RTC battery
 - PN532 RFID module V3
 - 5V 3007 Fan PWM Speed Adjustable CPU Cooling fan
 - LED, RGB model WS2812D
 - Cable for camera, MIPI 22-pin to FPC 15-pin (CSI), 8 cm
 - Lithium RTC clock battery, 3 V
 - Pi camera module 1, 2 or 3

 - ### Wiring schematics Raspberry Pi 5
Make sure to use the correct Lid as the camera modules differ in height. Use 2 mm screws with the right lenght.
