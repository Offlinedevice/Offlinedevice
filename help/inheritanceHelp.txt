
Inheritance package
-----------------------------

An inheritance package is a way to leave your encrypted data, such as passwords, login details for accounts and Bitcoin wallets etc, to a third party without risking that it gets stolen. It consists of three files:

1. The encrypted archive. This contains the parts from the Offline device that you have selected to include. It is encrypted with a seperate key.  
2. The encryption key.
3. A signature file. This is a signature file is created with your regular key for the encrypted (inheritance) archive. 

The encrypted file/archive can be decrypted on any Mac, Windows and Linux machine with GPG-software installed (almost all computers). The reciver don't need to have an Offline device or any graphical interface software. But ONLY if they have all parts: the file itself, the secret encryption key and the secret passsword. 
 
Don't use any of your regular passwords. USE AN EXTRA STRONG PASSWORD as both the key and encrypted archive is at the same custodian (or relative etc) and that makes it's very important to have a super strong password.

Your beneficiaries probably can gain access to your Offline device or backups etc. It's best to inform the beneficiaries who the trusted third parties are, e.g who to contact in case there is a need to recover the inheritance. Always tell the person with the password (your kids/husband/wife) to keep it hidden and stored in a safe manner (and not to mention it to any outsider).

The beneficiary (your children etc) who gets the secret password, that you used when creating the inheritance package, should also have a copy of your regular encryption key's public part (that you sign the inheritance with). With that public key they can later verify that it was really YOU that made and signed the archive.
It is also possible to make a timestamp on the Bitcoin blockchain for the combination of signature and archive. Then the beneficiary can know WHEN the files where first signed (by you).

It is best to give the inheritance package (a .tar file containing the three files) to more than one trusted person/company. The main idea is that the ones with the secret password should NOT have access to the inheritance package before you pass away (or decides to give it to them). 
It's a good idea to store the inheritance archive (.tar file) on a couple of high quality and dureable USB-device and make sure they are stored on seperate locations.

When creating an inhritance package a new entry will be added in your "Passwords"- file (select menu "Secure archive" to view it). This record also include the EXTRA STRONG PASSWORD you created. Copy it from there and give it to your beneficiaries in a secure way.

It can be a good idea to show the beneficiaries how to use the inheritance package (file) and the password. Or leave clear written down instructions. When creating an Inhritance package it is also possible to create a unique hardware key that can be used (with an Offline device) to recover an access a Inheritance. The password is stored in plain text on the hardware key so use the same strict security measures as for the written down password.
